# Changelog

## 0.1.1

- Added 3-zone layout to right panel cards (leading icons, content, trailing metadata and action buttons)
- Added active card selection (`SetSelected`) and background tinting without needing bracket tags
- Added right-aligned metadata text (`SetRightText`)
- Added left-aligned action buttons (`AddLeftButton`) in addition to right action buttons
- Added custom content escape hatch (`AttachCustomContent`) to mount custom UI hierarchies into cards
- Fixed bottom text and subtitle leaking out of card buttons due to line height and font sizing
